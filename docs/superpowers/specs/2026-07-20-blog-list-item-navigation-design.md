# 博客列表整项导航交互设计

## 目标

移除博客列表中的“查看详情”按钮，让每个博客列表项的完整浅灰色悬浮区域都可以直接进入当前页面已有的博客详情视图。

## 页面结构

- 博客列表继续展示标题、博客 ID、创建时间、更新时间和简介。
- 删除“查看详情”按钮及其专用布局容器。
- 不修改搜索框、加载状态、错误状态、空数据状态和列表底部统计。

## 导航交互

- 每个 `.blog-item` 继续复用现有 `viewBlogDetail(record.id)` 方法。
- 点击博客项任意位置均加载对应博客详情。
- 保留当前 `#f8fafc` 浅灰色悬浮背景、横向平移动画和手型光标。
- 博客项增加 `role="link"` 和 `tabindex="0"`，支持键盘聚焦。
- 按 Enter 或空格时加载博客详情；空格导航时阻止页面滚动。
- 键盘焦点使用清晰的蓝色轮廓，不改变鼠标悬浮颜色。

## 数据流和错误处理

- 不修改 `viewBlogDetail` 的参数校验、Ajax 请求、加载状态或错误提示。
- 点击或键盘触发后仍在当前 `PkIndexView.vue` 内从列表切换到详情，不增加新的路由。
- 博客详情继续使用 `MarkdownContent` 渲染正文。

## 测试

前端单元测试覆盖以下契约：

- 页面不再包含“查看详情”按钮。
- `.blog-item` 绑定鼠标点击、Enter 和空格事件。
- `.blog-item` 具有链接语义和键盘焦点能力。
- 当前浅灰色悬浮背景保持不变。
- `.blog-item` 保持手型光标并增加焦点轮廓。

## 非目标

- 不创建独立博客详情路由。
- 不修改博客详情内容、图片预览或 Markdown 行为。
- 不修改后端博客接口。
- 不修改博客创建和编辑页面。
