# 题库整行导航交互设计

## 目标

简化题库列表操作。移除题库页面中的添加题目、查看和删除按钮，让每一道题目的整行悬停区域都可以直接进入题目详情页。

## 页面结构

- 题库头部保留标题、题目数量和搜索框。
- 删除“添加题目”按钮及创建题目模态框。
- 题目表格只保留题号、标题/描述和难度三列。
- 删除“查看”和“删除”表头、单元格及按钮。

## 导航交互

- 每个题目 `<tr>` 绑定现有 `handleView(problem.id)` 导航方法。
- 鼠标悬停整行时沿用灰色背景，并显示手型光标。
- 行元素使用 `tabindex="0"` 和 `role="link"`，支持键盘聚焦。
- 按 Enter 或空格时进入对应题目详情页。
- 空格导航时阻止页面滚动。

## 代码清理

- 删除 `topicadd`、`addtopic`、`removetopic` 和 `errortopic`。
- 删除只服务于创建题目模态框的 `reactive`、Bootstrap `Modal` 引入。
- 保留 `useStore`，因为加载题目列表仍使用登录令牌。
- 不修改后端添加、删除题目的接口。

## 测试

前端单元测试覆盖以下契约：

- 页面不再包含“添加题目”“查看”“删除”操作按钮或相关方法。
- 表格不再包含查看和删除列。
- 题目行具有点击、Enter 和空格导航绑定。
- 题目行具有链接语义和键盘焦点能力。
- 悬停行显示手型光标。

## 非目标

- 不修改题目详情页。
- 不修改搜索、加载、错误和空数据状态。
- 不增加题目编辑或管理入口。
- 不删除或修改任何后端接口。
