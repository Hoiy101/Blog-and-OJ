# 后台管理背景图回归修复设计

## 问题与根因

应用在 `App.vue` 的 `body` 上设置了 `brck.avif` 全局背景图。后台管理页面新增的 `.admin-page-shell` 使用不透明的 `#f4f7fb` 背景并覆盖整个视口，因此背景图片仍然存在，但在三个管理页面中不可见。

## 修复方案

- 移除用户管理、登录记录和题库管理页面中 `.admin-page-shell` 的不透明背景声明。
- 继续保留 `.admin-page-shell` 的最小视口高度。
- 保留现有容器留白、白色卡片、边框、圆角、阴影和移动端适配。
- 由全局 `body` 背景自然透出，不在各管理页面重复引用图片资源。

## 测试

- 更新三个管理页面的布局回归测试，验证页面外壳不再声明不透明背景。
- 保留卡片结构、留白和边框断言，防止修复背景图时撤销上一轮视觉优化。
- 运行完整前端单元测试、Lint 和生产构建。

## 非目标

- 不修改全局背景图片及其尺寸策略。
- 不添加半透明蒙版。
- 不修改后台管理业务逻辑或模态框行为。
