# 后台管理页面留白与可滚动模态框设计

## 目标

改善用户管理、登录记录和题库管理三个页面的视觉层次，并确保题目或判例内容较长时，用户始终能够访问模态框底部的提交按钮。

## 页面布局

- 三个管理页面统一使用全宽浅灰色页面背景。
- 页面内容放入 Bootstrap `container`，桌面端四周保留约 24px 留白，小屏幕适当缩小。
- 标题、说明、操作按钮、状态提示和数据表格统一包裹在白色圆角卡片内。
- 卡片保留轻量边框和阴影，使其在浅灰背景上清晰可见。
- 表格仍使用响应式横向滚动，不改变现有数据和操作逻辑。

## 模态框滚动

- 新增/修改题目和修改判例模态框的最大高度限制在当前视口内，并保留上下安全间距。
- 模态框标题栏和底部操作栏保持可见。
- 只有中间内容区域上下滚动，长题目、长判例以及大量判例不会将提交按钮推到视口外。
- 新增题目和修改题目继续复用同一个 `TopicFormModal`，两种模式拥有一致的滚动行为。
- 删除确认模态框内容较短，不做额外滚动结构调整。

## 响应式与无障碍

- 在窄屏上减小页面留白，卡片仍占满可用宽度。
- 模态框使用 `max-height` 和弹性布局，避免依赖固定像素高度。
- 保留现有标题关联、关闭按钮、表单提交和加载禁用行为。

## 测试

- 增加页面布局测试，验证三个页面均具有统一的背景层、内容容器和外层卡片。
- 增加模态框结构测试，验证题目和判例模态框采用视口高度约束、弹性表单以及可滚动内容区。
- 运行完整前端单测、Lint 和生产构建。

## 非目标

- 不修改管理接口、数据格式或业务流程。
- 不重做表格为逐条卡片式列表。
- 不调整删除题目确认模态框。
